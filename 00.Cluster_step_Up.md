## 📖 Overview

This guide explains how to **create, manage, scale, and delete** an Amazon EKS (Elastic Kubernetes Service) cluster using `eksctl`, starting from a fresh Ubuntu EC2 instance.

### 🧰 What You Will Install

| Tool | Purpose |
|------|---------|
| **eksctl** | Create and manage EKS clusters from the command line |
| **kubectl** | Talk to the Kubernetes cluster (view nodes, pods, etc.) |
| **AWS CLI** | Authenticate with AWS and generate the kubeconfig |

## 🚀 Prerequisites: Launch an EC2 Instance

Create an **Ubuntu** EC2 instance.

> [!NOTE]
> Suggested instance: **t2.medium** or **t3.medium** with **16 GB** storage.

### 🔐 Attach an IAM Role

Attach an **IAM Role with Administrator permissions** to the EC2 instance.

> [!IMPORTANT]
> Create the IAM Role **before** launching the EC2 instance.

## 1. Install eksctl

Download and install the latest version of `eksctl`.

```bash
curl --silent --location "https://github.com/weaveworks/eksctl/releases/latest/download/eksctl_$(uname -s)_amd64.tar.gz" | tar xz -C /tmp

sudo mv /tmp/eksctl /usr/local/bin

eksctl version
```

**✅ Expected Output**

```text
0.xxx.x
```

## 2. Install kubectl

Download **kubectl**.

> [!NOTE]
> The URL `https://dl.k8s.io/release/stable.txt` always points to the latest stable Kubernetes release. At the time of writing, it downloads **kubectl v1.37.1**.

### 📦 Available Versions

| Kubernetes Version | Download Command |
|--------------------|------------------|
| **Latest Stable (1.37.x)** | `curl -LO "https://dl.k8s.io/release/$(curl -L -s https://dl.k8s.io/release/stable.txt)/bin/linux/amd64/kubectl"` |
| **v1.36.4** | `curl -LO https://dl.k8s.io/release/v1.36.4/bin/linux/amd64/kubectl` |
| **v1.35.8** | `curl -LO https://dl.k8s.io/release/v1.35.8/bin/linux/amd64/kubectl` |
| **v1.34.2** | `curl -LO https://dl.k8s.io/release/v1.34.2/bin/linux/amd64/kubectl` |

### Step 2.1 – Download, make executable, create the directory

```bash
curl -LO "https://dl.k8s.io/release/$(curl -L -s https://dl.k8s.io/release/stable.txt)/bin/linux/amd64/kubectl"

# Make it executable.
chmod +x kubectl

# Create the local binary directory.
mkdir -p ~/.local/bin
```

### Step 2.2 – Move kubectl

```bash
mv ./kubectl ~/.local/bin/kubectl
```

### Step 2.3 – Add kubectl to PATH

```bash
echo 'export PATH=$PATH:$HOME/.local/bin' >> ~/.bashrc

source ~/.bashrc
```

### Step 2.4 – Verify installation

```bash
kubectl version --client
```

**✅ Expected Output**

```text
Client Version: v1.xx.x
```

## 4. Create an Amazon EKS Cluster

> [!TIP]
> Cluster creation typically takes **15–20 minutes**. Keep the terminal open until it finishes.

### Example 1 – `my-eks-cluster` (2 nodes, us-east-1)

```bash
eksctl create cluster \
--name my-eks-cluster \
--nodegroup-name my-worker-node \
--node-type t2.medium \
--nodes 2 \
--managed \
--region us-east-1
```

### Example 2 – `demo` (1 node, us-east-2)

```bash
eksctl create cluster \
--name demo \
--nodegroup-name demo-node \
--node-type t2.medium \
--nodes 1 \
--managed \
--region us-east-2
```

### 🔎 Command Options Explained

| Option | Meaning |
|--------|---------|
| `--name` | Name of the EKS cluster |
| `--nodegroup-name` | Name of the worker node group |
| `--node-type` | EC2 instance type for the worker nodes |
| `--nodes` | Number of worker nodes |
| `--managed` | Use an AWS-managed node group |
| `--region` | AWS region where the cluster is created |

## 5. Delete an EKS Cluster

> [!WARNING]
> Deleting a cluster is **permanent**. Delete clusters when you are done to avoid unnecessary AWS charges.

### Delete the first cluster

```bash
eksctl delete cluster \
--name my-eks-cluster \
--region us-east-1
```

### Delete the second cluster

```bash
eksctl delete cluster \
--name demo \
--region us-east-2
```

## 6. Update kubeconfig (Troubleshooting)

If `kubectl` cannot connect to the cluster, update the kubeconfig.

```bash
aws eks update-kubeconfig \
--region us-east-1 \
--name my-eks-cluster
```

Verify connectivity.

```bash
kubectl get nodes
```

---

## 7. Scale the Node Group

Increase worker nodes from **2** to **3**.

```bash
eksctl scale nodegroup \
--cluster my-eks-cluster \
--name my-worker-node \
--nodes 3 \
--region us-east-1
```

Verify.

```bash
kubectl get nodes
```
