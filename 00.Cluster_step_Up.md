# Amazon EKS (Elastic Kubernetes Service) Setup Guide

This guide explains how to create, manage, scale, and delete an Amazon EKS cluster using `eksctl`.

---

# Prerequisites : Launch an EC2 Instance

Create an Ubuntu EC2 instance. 

> **Note:** Suggested t2.meduim or t3.medium with 16Gb Storage

### Attach an IAM Role

Attach an IAM Role with Administrator permissions to the EC2 instance.

> **Note:** Create the IAM Role before launching the EC2 instance.

---

# 0. Update & upgrade and install Tree, unzip

```bash
sudo apt -y update && sudo apt -y upgrade
sudo apt install tree plocate unzip

```

# 1. Install eksctl

Download and install the latest version of `eksctl`.

```bash
curl --silent --location "https://github.com/weaveworks/eksctl/releases/latest/download/eksctl_$(uname -s)_amd64.tar.gz" | tar xz -C /tmp

sudo mv /tmp/eksctl /usr/local/bin

eksctl version
```

Expected Output

```text
0.xxx.x
```

---

# 2. Install kubectl

Download kubectl.

```bash
curl -LO "https://dl.k8s.io/release/$(curl -L -s https://dl.k8s.io/release/stable.txt)/bin/linux/amd64/kubectl"
```

Make it executable.

```bash
chmod +x kubectl
```

Create the local binary directory.

```bash
mkdir -p ~/.local/bin
```

Move kubectl.

```bash
mv ./kubectl ~/.local/bin/kubectl
```

Add kubectl to PATH.

```bash
echo 'export PATH=$PATH:$HOME/.local/bin' >> ~/.bashrc

source ~/.bashrc
```

Verify installation.

```bash
kubectl version --client
```

Expected Output

```text
Client Version: v1.xx.x
```

---

# 3. Install AWS CLI

Download AWS CLI.

```bash
curl "https://awscli.amazonaws.com/awscli-exe-linux-x86_64.zip" -o "awscliv2.zip"
```

Extract.

```bash
unzip awscliv2.zip
```

Install.

```bash
sudo ./aws/install
```

Verify installation.

```bash
aws --version
```

Expected Output

```text
aws-cli/2.xx.x
```

---

# 4. Create an Amazon EKS Cluster

## Example 1

```bash
eksctl create cluster \
--name my-eks-cluster \
--nodegroup-name my-worker-node \
--node-type t2.medium \
--nodes 2 \
--managed \
--region us-east-1
```

---

## Example 2

```bash
eksctl create cluster \
--name demo \
--nodegroup-name demo-node \
--node-type t2.medium \
--nodes 1 \
--managed \
--region us-east-2
```

---

# 5. Delete an EKS Cluster

Delete the first cluster.

```bash
eksctl delete cluster \
--name my-eks-cluster \
--region us-east-1
```

Delete the second cluster.

```bash
eksctl delete cluster \
--name demo \
--region us-east-2
```

---

# 6. Update kubeconfig (Troubleshooting)

If `kubectl` cannot connect to the cluster, update the kubeconfig.

```bash
aws eks update-kubeconfig \
--region us-east-1 \
--name my-eks-cluster
```

Verify connectivity.

```bash
kubectl get nodes
```

---

# 7. Scale the Node Group

Increase worker nodes from **2** to **3**.

```bash
eksctl scale nodegroup \
--cluster my-eks-cluster \
--name my-worker-node \
--nodes 3 \
--region us-east-1
```

Verify.

```bash
kubectl get nodes
```


